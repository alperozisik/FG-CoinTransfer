Coin Transfer for Fantasy Grounds 5E, with an English interface for party coin transfers and weighted physical coins.

Changes in 0.1.4:
- Embed the full MIT license in the standalone archive as LICENSE.txt.
- Build reproducible packages with version and Forge filename validation; exclude the development harness.
- Add synthetic fixtures, acceptance evidence, installation/update/removal guidance, and real product screenshots.

Validation: 8 offline tests, 44 native FG assertions, and all four operations from a separate owning player passed. Reload preserved balances and container preferences. Tested with FG 5.1.15, 5E/CoreRPG 2026-10-06, Default theme, only Coin Transfer enabled. Separate 2014/2024 configurations and other-extension combinations are unverified for this version. The bare-5E optional Floating Tabs merge warning is documented.
