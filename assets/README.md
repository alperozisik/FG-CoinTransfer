# Original icon

`coin-transfer-icon.svg` is original source-drawn artwork for Coin Transfer, under the repository MIT license. The coin and opposing arrows use simple geometric primitives, without FG/D&D logos or third-party graphics.

`coin-transfer-icon.png` (512 square) and `coin-transfer-icon-96.png` are raster derivatives for listing/thumbnail review. Recreate them with `python assets/render_icon.py` if Pillow is available. This optional artwork tool is not needed to build or run the extension.

These are not screenshots and are not currently registered as an FG runtime control icon. Review thumbnail legibility and any eventual FG usage during the authorized UI session before making that claim. The Forge first image is the separate illustrative cover in `docs/forge/images/`.
